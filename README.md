# ask-me-nothing

**Teaching financial agents to ask less and leak nothing: multi-turn RL in a simulated brokerage desk.**

Final project for ECE 6256 / CS 6604 Conversational AI (Georgia Tech, Fall 2026, Prof. Larry Heck).
Team: Greyson, Michael Incorvaia, Heeba, Canting.

## The idea

In financial dialogue every clarifying question is also a request for client data. Agents that ask by habit waste the client's time, cost money while prices move, and collect sensitive information they never needed. We train a small model (1.5 to 3B) with multi-turn GRPO to decide, turn by turn, whether to **ask, look up, think, or act**, with a price on every question and on every sensitive field it collects. The goal is a need-to-know policy: look up or derive what it can, ask only what the rules require or the client alone knows, never leak one client's data, and still finish the task.

Research questions (details in [`docs/PLAN.md`](docs/PLAN.md)):

1. **RQ1.** Can multi-turn GRPO beat prompting and SFT distillation on success, pass^k, and dollars lost?
2. **RQ2.** Does pricing sensitive data teach data minimization without hurting success?
3. **RQ3.** What did training change: fewer redundant questions, kept mandatory ones, better thinking allocation?
4. **RQ4.** Does it transfer from scripted to LLM-simulated clients and resist injected data requests?

## Setup

Requires Python 3.10+. We use [uv](https://docs.astral.sh/uv/) for a pinned, reproducible environment; plain `pip` works too.

```bash
git clone https://github.com/IncorvaiaM1/ask-me-nothing.git
cd ask-me-nothing

# simulator + tests only (laptop)
uv venv && uv pip install -e ".[dev]"
pytest -q

# add training dependencies (PACE-ICE GPU node)
uv pip install -e ".[train]"

# add API baselines (frontier and LLM-simulated clients)
uv pip install -e ".[api]"
cp .env.example .env   # then fill in your own keys; .env is gitignored
```

Without uv: `python -m venv .venv`, activate it, then `pip install -e ".[dev]"`.

Once the RL library is chosen (Nov 1), we pin every dependency with `uv lock` and commit `uv.lock`.

## Conventions

- Seeds are fixed and passed explicitly; no unseeded randomness in `brokerdesk/`.
- Every prompt lives in `prompts/` as a plain text file; code loads it from there, never inline.
- No real client data, ever. All personas and values are synthetic, and every value carries a canary string so leaks are detectable by string match.
- No API keys or PACE credentials in git. Use `.env`.
- Work on a branch per workstream and open a PR into `main`.

## Data statement

All client profiles, portfolios, and tasks are synthetic and generated by `brokerdesk/tasks.py`. No personal data is collected or used, and no human subjects are involved. The simulator is a research tool and not investment advice.
